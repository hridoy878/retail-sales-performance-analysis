# Retail Sales Performance Analysis | Power BI

An interactive Power BI dashboard built to analyze retail sales, profitability, product categories, customer segments, and regional performance using the Superstore dataset.

## 📊 Project Overview

The goal of this project is to transform retail sales data into meaningful business insights. The dashboard helps identify sales trends, profitable product categories, regional performance, and potential areas for business improvement.

This project demonstrates practical skills in data analysis, data visualization, and business intelligence using Microsoft Power BI.

## 🎯 Project Objectives

* Analyze overall sales and profitability.
* Compare sales performance across product categories and regions.
* Explore customer segments and purchasing patterns.
* Identify opportunities to improve profitability.
* Present business insights through an interactive dashboard.

## 🛠️ Tools & Technologies

* **Microsoft Power BI** — Dashboard development and visualization.
* **Power Query** — Data preparation and transformation.
* **Superstore Dataset** — Retail sales and profit data.

## 📁 Dataset Information

The dataset contains retail transaction records with the following fields:

| Field         | Description                     |
| ------------- | ------------------------------- |
| Order Date    | Date the order was placed       |
| Ship Date     | Date the order was shipped      |
| Ship Mode     | Shipping method                 |
| Customer Name | Customer identification         |
| Segment       | Customer segment                |
| Region        | Sales region                    |
| State         | State associated with the order |
| Category      | Product category                |
| Sub-Category  | Product subcategory             |
| Sales         | Sales amount                    |
| Quantity      | Number of items sold            |
| Discount      | Discount applied                |
| Profit        | Profit or loss from sales       |

**Dataset source:** [Kaggle — Superstore Dataset](https://www.kaggle.com/datasets/ishanshrivastava28/superstore-sales)

The dataset was originally associated with Tableau's Sample Superstore data and is used here for educational and portfolio purposes.

## 📈 Dashboard Features

The dashboard includes three KPI cards and four visualizations to summarize sales performance.

### Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders or another selected performance metric

### Visualizations

The dashboard contains four charts designed to explore sales and business performance across different dimensions.

These visualizations support comparisons of product performance, regional sales, category-level results, and other relevant business trends.

*Note: The exact chart titles and metric definitions should match the visuals in the Power BI report.*

## 💡 Business Questions

This analysis aims to answer questions such as:

1. Which product categories generate the highest sales?
2. Which regions perform best in terms of sales and profit?
3. Which products or subcategories may require improvement?
4. How do customer segments contribute to overall sales?
5. Where could the business focus its efforts to improve profitability?

## 📌 Business Value

The dashboard can help business stakeholders:

* Identify strong and weak sales areas.

* Support data-driven inventory and sales decisions.
* Discover opportunities to improve business performance.

## 🚀 How to Use the Project

1. Download `Retail_Sales_Performance_Analysis.pbix` from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Interact with the charts and available filters to explore the data.
